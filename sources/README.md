# Evidence sources

**You do not need to put anything here.** Steve searches the web himself at each research step and can only
cite pages his code actually downloaded. Pages saved in this folder are optional extra evidence: they are
ranked alongside the web results, and they are the only evidence when `WEB_SEARCH=false` (for a run with no
internet).

## Format (optional pages)

One page per file, `.md` or `.txt`, with a short header, a blank line, then the page text:

```
URL: https://example.com/pricing
Title: Example pricing page
Retrieved: 2026-11-17

...the text of the page...
```

This file is ignored by the loader.

## What to save

For whichever idea the demo uses, aim for 8 to 12 pages:

- competitor product pages and their pricing pages
- marketplace or directory listings showing what already exists
- public statistics about the market or the audience
- the pricing pages of the tools the project would pay for (hosting, domain, email)
- platform terms or licence pages relevant to the intellectual property checklist

Saving them by hand is fine: open the page, copy the text, add the header. Keep each file small —
a few hundred to a couple of thousand words is plenty.
